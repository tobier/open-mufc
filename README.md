## Supported modules

| Aircraft | Status | Comment |
| --- | :---: | --- |
| AJS-37 | 🚧 | In progress, rudimentary CK 37 support added |
| F-16C | ✅ | Supports DED, CMDS and (some) lights |
| F/A-18C | ❌ | Planned, not yet implemented |
